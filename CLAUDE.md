# JFSN Archive — Claude Code Design Brief

## Project
Personal archive site for Jeffrey F. S. Neumann — 1,084 works spanning 1974–present.
Collage, sculpture, photography. This is a personal record, not a promotional platform.
Making is the point.

Live: jfsn.com (cPanel) and jfsn-archive.netlify.com (Netlify, has Companion edge function)

---

## Design System

### Tokens (from site.css)
```
--bg:      #0b0b0b          /* near-black — always dark, never light */
--text:    #f3f0ea          /* warm cream — not pure white */
--muted:   rgba(243,240,234,0.62)
--dim:     rgba(243,240,234,0.12)
--accent:  #FF6600          /* burnt orange — used sparingly */
--font-display: 'Cormorant Garamond', Georgia, serif
--font-body: Inter, -apple-system, sans-serif   /* currently, but NOT preferred */
```

### Typography rules
- Display/headlines: Cormorant Garamond — light weight (300), often italic
- UI labels: ALL CAPS, tight letter-spacing (0.08–0.18em), ~0.625–0.75rem
- Body text is sparse — the work does the talking
- **Do not use Inter as a positive choice.** It is the fallback body font but adds no character.
  For any new text-heavy sections, explore alternatives: Freight Text, Source Serif, or system-serif.

### Visual language
- Dark ground always — images read better, gallery feel
- Warm cream on near-black: never cold white, never pure black
- Orange accent (#FF6600) for active states, hover emphasis, progress bar — not decoration
- No gradients. No drop shadows on images. No cards with visible backgrounds.
- Borders use `var(--dim)` (12% opacity) — barely-there structure
- Spacing is generous — crowding kills the work

### What NOT to do (anti-patterns)
- No purple, blue, or teal accents
- No Inter as a design choice (only as a fallback)
- No white or light-mode pages — dark ground is the identity
- No card UI with filled backgrounds — images float on the dark ground
- No decorative dividers, badges, or icons unless functional
- No AI-default layouts: centered hero + three-up cards + CTA button = avoid

## Architecture

### Files
- `site.css` — global tokens, nav, footer, shared utilities
- Per-page `<style>` blocks — page-specific layout only
- `catalog.json` / `catalog-home.json` — work data, generated by `ingest.py`
- `search.js` — site-wide search overlay (⌘K)
- `companion.html` + Netlify edge function — AI companion feature

### Conventions
- No frameworks. Vanilla HTML/CSS/JS throughout.
- CSS custom properties for all tokens — never hard-code colors
- Lazy-load images with `loading="lazy"` and explicit `width`/`height`
- ARIA roles and labels on all interactive elements
- `prefers-reduced-motion` respected in all transitions
- `aria-current="page"` on active nav link

### Deployment
- End session: `bash end-session.sh` or double-click "Deploy JFSN.command"
- Start session: read `CURRENT_STATE.md` first

## Content philosophy
- Archive first — every decision serves the work, not the designer
- No calls to action, no newsletter signups, no engagement patterns
- Descriptions are spare — year, medium, dimensions if known
- SEO metadata exists for discoverability but never shapes the on-page experience

---

## UX priorities
1. The image is the primary object — UI recedes
2. Fast load on slow connections (archive has 1,084 items — virtual scroll, lazy load)
3. Filter/search must be instant-feeling
4. Mobile: iPhone 15 Pro is the primary test device
5. Accessibility: WCAG AA contrast, keyboard nav, screen reader labels
