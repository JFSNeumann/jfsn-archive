scene is a face in a *depicted* artwork, not a primary object.

## Why the motif name is misleading

`photographic-face` fires on face-like forms generally, not on photographs of people. Sampling
the images directly (not the descriptions) showed the label is unreliable in both directions:

- **art0614** — description says the face is "rendered in dense, overlapping black scrawled
  lines," which reads as drawn. The image shows a **real photographed face** with eyes and nose
  clearly photographic, overdrawn with ink. Classified drawn; is photographic.
- **art1077** — a straight colour portrait photograph of one identifiable person, sunglasses and
  scarf. No ambiguity.
- **art0326, art0491, art0553** — painted, schematic and constructed faces. Real objects, but
  **there is no person in them to name.**

Classifying by description was attempted and abandoned: it sorts 84 as drawn, 34 as photographic,
22 ambiguous, 97 unstated — but the two spot-checks above both fell in the wrong bucket. The
descriptions are machine-written, so that method classifies *machine text about a machine
label*. Two layers of inference, no primary evidence. **The list can only be pinned visually.**

## The recommended working list

Not 268. In this order:

1. **The 30 non-composite Collaboration works.** Made *with* the grandchildren. Smallest pile,
   highest value, and the one that answers the archive's guiding question literally.
2. **The ~7 self-identifying works above.** Jeff confirms or corrects what the object already
   says. Fast, and it establishes each child's face as an anchor.
3. **art1077 and the unambiguous portrait photographs.** A real person, one per work.
4. **The remaining face-motif works, visually triaged first** — with the painted and schematic
   faces removed, because they contain nobody.
