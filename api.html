Design System

Principles

Archive first. Every decision serves the work, not the designer.

Light ground. Bone-white or near-white background, deep-ink text.

Orange accent. #FF6600 for hover, active states, links — not decoration.

No gradients, no rounded corners. Clarity through simplicity.

Full color always. Artwork thumbnails keep saturated color at all times.

Accessibility

Contrast rules:

  • #FF6600 (orange) on dark backgrounds only (6.7:1)
  • #B84700 (orange-ink) for text on light backgrounds (5.07:1 AA)
  • #0B0B0B (deep-ink) on light backgrounds (16:1)

Keyboard navigation:

  • All interactive elements focusable with Tab
  • Focus rings: 2px solid #FF6600
  • Shortcuts: ⌘K (search), ⌘Shift+D (design system), ← → (decade nav)

Motion: Respect prefers-reduced-motion: reduce — disable all entrance animations, keep transitions instant.

Developer

Open Archive API

Static JSON endpoints for every work in the archive. No key, no rate limit, no authentication — just plain files served over HTTPS. Stable URLs you can cite, link, and build on indefinitely.

Base URL — https://jfsn.com/api/v1/
All responses are Content-Type: application/json; charset=utf-8 with Access-Control-Allow-Origin: *. Safe to call from any browser or script.

Quick start

Get all cataloged works: 

curl https://jfsn.com/api/v1/works.json

Get a single work: append the artwork ID (e.g., art0005.json). Browse by theme: fetch themes.json, find your theme, use the work_ids array. All endpoints are static files — cache-friendly and CDN-served. Full reference below →

Usage examples

curl

# All cataloged works
curl https://jfsn.com/api/v1/works.json

# Single work
curl https://jfsn.com/api/v1/works/art0005.json

# All Aviation works
curl https://jfsn.com/api/v1/themes.json \
  | jq '.themes[] | select(.name=="Aviation") | .work_ids'

JavaScript (fetch)

// Fetch a single work
const res = await fetch(
  'https://jfsn.com/api/v1/works/art0005.json'
);
const { work, links } = await res.json();

// All Aviation works
const t = await fetch(
  'https://jfsn.com/api/v1/themes.json'
).then(r => r.json());
const aviation = t.themes.find(
  x => x.name === 'Aviation'
);

Python

import requests, json

# List all works with palette including 'gold'
works = requests.get('https://jfsn.com/api/v1/works.json').json()['works']
gold_works = [w for w in works if 'gold' in w.get('palette', [])]
print(f"{len(gold_works)} works featuring gold")

# Download metadata for a specific work
work = requests.get('https://jfsn.com/api/v1/works/art0001.json').json()
print(work['work']['title'], '—', work['work']['description'])

CSV exports

The JSON endpoints work directly with spreadsheet tools and data analysis software. Convert to CSV for Excel, Google Sheets, or research databases:

Python (pandas)

import pandas as pd

# Download all works and save as CSV
url = 'https://jfsn.com/api/v1/works.json'
data = pd.read_json(url)
works_df = pd.json_normalize(data['works'])
works_df.to_csv('jfsn-archive.csv', index=False)

# Keep only essential columns
essential = works_df[['file', 'title', 'year', 'work_type', 'themes', 'palette']]
essential.to_csv('jfsn-archive-minimal.csv', index=False)

Shell (jq + csvkit)

# Fetch and convert to CSV with jq
curl https://jfsn.com/api/v1/works.json \
  | jq -r '.works[] | [.file, .title, .year, .work_type] | @csv' \
  > jfsn-archive.csv

# Or use csvkit for more control
curl https://jfsn.com/api/v1/works.json \
  | jq '.works' | in2csv --format json > jfsn-archive.csv

Google Sheets

Use the =IMPORTDATA() or =IMPORTJSON() function (via extensions like JSON Import Plugin): 

=IMPORTJSON("https://jfsn.com/api/v1/works.json", "works")

Researcher's data guide

Years are decade estimates — Every work's year (1974–2020s) is extracted from visual evidence on the piece itself, not from external records. All 1,084 years are estimates assigned to decade buckets (1970s, 1980s, etc.); even works with visible single years are rounded to the decade. When analyzing temporal patterns, treat the year as ±5 years uncertainty. Query: use year_precision: "estimated" in each work record and year_display: "1990s (est.)" for display.
Composites are flagged, not real — ~250 works are marked composite: true. These are Photoshop composites showing imagined placements (e.g., how a work might look in a gallery), NOT photographs of real exhibitions. The gallery-images.html page explains this directly. For archival/historical analysis, use composite: false to filter to real single works.
Themes & motifs are subjective — The 14 themes (Guernica, Targets, Crosses, etc.) and 30 motifs (compact-disc, warplane-topdown, etc.) are curatorial selections, not machine-tagged. They reflect patterns the creator recognized, not exhaustive indexing. Use them for thematic discovery, not statistical completeness.
Physical dimensions are partial — The orientation field (vertical / horizontal / square) is derived from image aspect ratios, not real-world measurements. Actual inches/centimeters are not yet digitized; contact for specific works.

Recommended queries: Filter by composite: false + work_type: "collage" to find real collages. Group by decade to track stylistic evolution (mindful of the ±5 year range). Use themes and motifs for thematic research, not quantitative claims about the archive. Always cite year_display (e.g., "1990s (est.)") when publishing.

Research pathways

Curatorial exploration: Start with Curatorial Map to see all 1,084 works in a decade × medium grid with theme overlays. Then use the API to fetch full metadata for works in your areas of interest.

Color-driven research: Fetch palette.json to find all works featuring a specific color (e.g., all works with "gold"). Cross-reference with Chromatic River, an interactive canvas of all works sorted by year and color.

Theme & series analysis: Use themes.json (14 curatorial themes) and series.json (3 named bodies: XXIII, Squadron, Guernica) to explore recurring motifs and interconnected works. Each endpoint includes the archive browse URL for interactive browsing.

Temporal patterns: Sort works by decade (using year_display and the ±5 year caveat) to track stylistic evolution. Medium breakdown (work_type) shows which materials dominate each era.

Individual work study: Each artwork's page (e.g., jfsn.com/artwork.html?id=art0005) includes the full metadata, a high-resolution lightbox, and links to related works in the same series or theme. The JSON endpoint /api/v1/works/art0005.json carries the same data in machine-readable form.

Versioning & stability

URL stability guarantee — the path https://jfsn.com/api/v1/works/{id}.json will exist for as long as this archive exists. Artwork IDs are never reassigned or deleted; new works get new IDs.
Schema versioning — every response includes "api_version": "1". If the schema changes incompatibly, a new /api/v2/ path is introduced; v1 is kept frozen. The schema_version inside each work record tracks the AI cataloging schema independently.
No rate limits — all endpoints are static files served from CDN edge nodes. There is no server-side processing; you cannot overload it. Cache-Control headers suggest 1-hour freshness.
