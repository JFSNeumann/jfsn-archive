# Automobile Designs Gallery

This folder contains images for the Automobile Designs showcase page.

> **Note:** The folder name contains a typo (`automoblie` instead of `automobile`). This is intentional to maintain existing file paths and references.

## 📁 Folder Location

- **Actual folder path:** `images/automoblie-designs/`
- **Showcase page:** `/automobile-designs.html`

## 🖼️ Adding Images

1. Place your automobile design images in this folder (`images/automoblie-designs/`)
2. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`
3. The page will automatically display all images in a masonry grid layout

## 📝 Image Naming

For best results, name your images descriptively:
- `concept-car-2024.jpg`
- `sports-car-design.jpg`
- `electric-vehicle-concept.png`

## ⚙️ Image Recommendations

- **Recommended size**: 1200px - 2000px wide
- **Aspect ratio**: Any (masonry layout adapts)
- **File size**: Optimize images for web (under 500KB each recommended)
- **Format**: Prefer `.webp` or `.avif` for better compression

## 🔗 Related Files

- **Gallery page:** `/automobile-designs.html`
- **Gallery script:** `scripts/generate-automobile-gallery.js` (if applicable)
